1工作台里有什么

板块用来干什么

数据透视各板块数据统计：总览看关键指标；自定义透视按「维度 × 指标」交叉统计，自动出表格和条形图
地图写字楼分布图，按片区查看楼宇位置

2怎么录入和修改数据

询盘管理

点 + 新增询盘 填写客户信息；点列表里任一条可查看 / 编辑 / 删除。详情里每个楼盘有「已问 / 合适 / 不合适」标记，点「笔记」可贴微信里的跟进文字。

单独添加盘源（不依赖片区）：在询盘详情的「楼盘询盘进度」里点 + 添加盘源，填写楼盘名称、选择所属片区、可顺手把盘源信息（租金 / 面积 / 免租 / 装修等）一起记下来。该盘会进入「手动添加盘源」分组，同样能标合适 / 不合适 / 写笔记，点 ✕ 可移除。即使这条询盘没选任何片区也能用。

楼盘库

点 + 新增楼盘 填租金、免租期、管理费、等级等；支持「新增片区」自定义分区；楼盘可改名或迁移片区（跟踪标记会跟着搬）。

市场动态

点 + 新增成交 记录企业 / 项目 / 面积 / 租金 / 类型；点已有记录可编辑。

客户管理

点 + 新增客户 登记拜访（16 字段）；点已有记录可编辑 / 删除。

客户跟进

点 + 新增跟进 登记客户的办公地点 / 租金 / 目标搬迁 / 卡点；选「搬迁状态」会自动展开对应字段（不搬迁→到期时间；已搬迁→搬迁至楼宇+租金+租期）；点表格第一列的 ☆ 可把重点客户置顶，点 ★ 取消。

📊 数据透视怎么用

  1. 切到「数据透视」板块，先看 总览：自动汇总各板块的关键指标卡片。
  2. 点 自定义透视 标签页，依次选：板块（询盘/成交/楼盘/客户）→ 统计维度（如按商务区、按行业）→ 指标（如面积、租金）→ 计算方式（计数 / 求和 / 平均）。
  3. 页面自动生成统计表格 + 条形图，用来快速看分布和对比。

📝 贴微信笔记

在「询盘管理」点开某条客户，找到下方楼盘列表里的 笔记 按钮 → 把微信聊天里复制的盘源 / 跟进文字粘贴进去 → 保存。保存后按钮变成「笔记✓」，下次打开还能看到。

3批量导入（Excel / CSV / 图片 / 粘贴）

入口

  • 顶栏 导入数据：按当前所在板块导入（询盘 / 成交 / 楼盘 / 客户）。
  • 各板块自己的 导入询盘 / 导入市场动态 / 导入楼盘 / 导入客户 / 导入客户跟进。

三种导入方式

  • ① 文件：选 Excel(.xlsx/.xls) 或 CSV。系统自动识别表头，多 sheet 的可选具体工作表。
  • ② 粘贴文字：从表格复制整段（带表头最好），或一行一条流水，例如 企业名-New Setup-550sqm-君超中心32F-145，点「解析」自动抽字段。
  • ③ 图片识别：上传盘源截图 / 拍照，识别文字后再解析（识别不准时可手动改）。

导入流程

  1. 选文件 / 粘贴 / 上传图片后，进入预览表格。
  2. 可逐格修改、勾选要导入的行、系统会标出重复项。
  3. 选重复处理方式：跳过 / 更新 / 追加。
  4. 点 确认导入，数据写入对应板块。
建议：大批量导入前，先点顶栏「导出备份」存一份，万一导错可恢复。

4导出与备份

两种导出

  • 导出全部：顶栏 导出Excel → 生成一个文件，内含「询盘 / 成交 / 客户 / 楼盘」四个工作表。
  • 单独导出某板块：切到对应板块，点它的 导出询盘Excel / 导出市场动态Excel / 导出客户Excel / 导出楼盘Excel / 导出客户跟进Excel。
导出的是当前全部数据（不受页面筛选影响），自动下载到「下载 / 文件」目录。

备份 / 恢复

  • 导出备份：存一份完整备份文件（推荐定期做）。
  • 恢复备份：换设备或误删后，从备份文件把数据导回来。

打开导出文件

  • WPS：直接双击，无提示。
  • Microsoft Excel：若弹「文件格式与扩展名不匹配」，点 「是」 即可正常打开，内容完全正常。

5团队协作（云端同步，配置一次）

默认每个人数据只存在自己设备上，互相看不到。想让团队看同一份询盘和市场动态，做一次同步配置即可——任何人的改动会几秒内同步给所有人。

  1. 点右上角的同步按钮（默认显示 本地模式）。
  2. 模式切到 「云端（Supabase 共享）」。
  3. 填入管理员发的三项：Supabase URL、匿名 Key、团队空间 Key。
  4. 点 保存；按钮变成绿色「云端·已同步」即配置完成。
  5. 点 生成配置链接 → 复制该链接：收藏给自己（以后免手填），或 发给同事（对方打开即自动进同一云端空间）。
只发网址、不发配置链接 = 对方只能打开工具、录自己的数据，看不到你的任何数据。所以工作台链接可以放心转发。
团队空间 Key 相当于团队密码，所有人必须填完全相同的三项才会进同一个数据空间；不同团队请用不同 Key 隔离，勿发到公开群。

6把它装成手机 App

添加到主屏幕后，图标和使用体验跟普通 App 一样，全屏打开、没有浏览器地址栏，弱网也能看已缓存数据。

iPhone（Safari）

  1. 用 Safari 打开上面的网址（微信里点开的话，先点右上角「…」→「在 Safari 中打开」）
  2. 点底部中间的 分享按钮 ⬆️
  3. 下滑选 「添加到主屏幕」 → 右上角「添加」

安卓（Chrome / 浏览器）

  1. 用系统浏览器打开网址
  2. 点右上角 「⋮」菜单
  3. 选 「添加到主屏幕」 或「安装应用」

7常见问题

  • 打开是旧版 / 看不到新功能？
    电脑按 Ctrl+Shift+R（Mac 是 Cmd+Shift+R）强制刷新；手机把 App 关掉重开，或在浏览器清一下该站点缓存。
  • 数据会丢吗？
    默认存在本机浏览器。建议定期点 导出备份 存一份；换设备用「恢复备份」找回。配置了云端同步则以云端为准。
  • 清理浏览器数据会怎样？
    会清掉本机数据，所以重要数据务必先备份，或开启云端同步。
  • 可以离线用吗？
    可以。装到主屏幕后，没网也能看已缓存内容；联网后云端同步自动补齐。
  • 网址会变吗？
    不会。固定正式网址，后续功能更新直接生效在同一地址，不用重新收藏。
